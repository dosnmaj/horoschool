Что делает Проблема Без него
01

Редактор кода VS Code

Что делает
Место, где пишется код: подсветка синтаксиса, автодополнение, поиск по проекту, расширения, встроенный терминал.
Какую проблему решает
Писать код быстро и без мелких ошибок: незакрытый тег или опечатку в имени переменной видно сразу.
Если его нет
Код в «Блокноте»: всё одним цветом, ошибки ищутся глазами, на любую правку уходит в разы больше времени.
02

Терминал командная строка

Что делает
Даёт управлять компьютером командами: запускать программы, ставить пакеты, работать с Git, создавать файлы.
Какую проблему решает
Одна команда заменяет десяток кликов, а повторяющиеся действия можно автоматизировать скриптом.
Если его нет
Большинство инструментов разработки просто не запустить: у Git, npm и Python нет кнопок, только команды.
03

Git контроль версий

Что делает
Сохраняет историю изменений проекта коммитами: кто, что и когда поменял. Позволяет вести ветки.
Какую проблему решает
Можно откатиться к рабочей версии и пробовать новое в отдельной ветке, не ломая основное.
Если его нет
Папки «site_final», «site_final_2», «site_точно_финал». Одна неудачная правка — и рабочая версия потеряна.
04

GitHub удалённый репозиторий

Что делает
Хранит Git-репозиторий в облаке: код, история, задачи (Issues), обсуждение изменений (Pull Requests).
Какую проблему решает
Код доступен с любого компьютера, над ним могут работать несколько человек, а проект можно показать как портфолио.
Если его нет
Код живёт на одном ноутбуке: сломался диск — проект пропал. Командная работа превращается в пересылку архивов.
05

Браузер и DevTools F12

Что делает
Показывает результат и даёт заглянуть внутрь: HTML-структура, CSS-стили, консоль с ошибками JavaScript, сеть, вид на телефоне.
Какую проблему решает
Видно, почему блок «уехал» или скрипт не работает. Стили можно подбирать вживую, без перезаписи файла.
Если его нет
Отладка вслепую: «почему не работает» решается методом тыка, а мобильная вёрстка проверяется только на реальном телефоне.
06

GitHub Pages хостинг / публикация

Что делает
Превращает репозиторий с index.html в настоящий сайт по ссылке вида имя.github.io/проект.
Какую проблему решает
Сайт можно бесплатно показать любому человеку, без покупки сервера и настройки домена.
Если его нет
Сайт открывается только у автора на компьютере. Заказчику или преподавателю остаётся смотреть скриншоты.

Выпадает любое звено — цепочка рвётся: код либо нельзя написать удобно, либо проверить, либо сохранить, либо показать.
